# Minna

> Named after Minerva the Roman goddess of Wisdom.

# Installation
To install, download the latest `minna.app` from the [Releases Page](https://github.com/impel-intelligence/Minna/releases/latest).

## Setup
To use Minna you need to provide an AI provider. Claude / Anthropic is the only provider currently supported.

The first step is to open settings, <kbd>cmd</kbd> <kbd>+</kbd>
<img width="902" height="612" alt="Screenshot 2026-07-17 at 3 01 17 PM" src="https://github.com/user-attachments/assets/eeedb5ce-434c-4a14-a465-fdf69883b03d" />

Then scroll down to "Add a new provider" and select "Claude (Anthropic)". In this view you can name your provider instance, and enter your API key.

## Sample Data
Minna works best when you provide it with data. To make finding data easier, a sample of Open Course Work can be [downloaded here](https://github.com/impel-intelligence/Minna/releases/download/0.6.1/Open.Course.Materials.zip).
